Stack and Queue Implementation in C++

📌 Project Overview

This project demonstrates the implementation of Stack and Queue data structures in C++ using arrays and linked lists. It explains how different data structures work and how their basic operations are performed.

📚 Programs Included

1. Stack Using Array

A stack is a linear data structure that follows the LIFO (Last In, First Out) principle.

Operations:

- Push – Insert an element into the stack.
- Pop – Remove the top element.
- Peek – Display the top element.
- Display – Show all stack elements.

2. Stack Using Linked List

This program implements a stack using a linked list. Each node stores data and a pointer to the next node.

Operations:

- Push – Insert an element at the top.
- Pop – Remove the top element.
- Peek – View the top element.
- Display – Show all stack elements.

Advantage: The stack can grow dynamically as memory is allocated when required.

3. Queue Using Array

A queue is a linear data structure that follows the FIFO (First In, First Out) principle.

Operations:

- Enqueue – Insert an element at the rear.
- Dequeue – Remove an element from the front.
- Peek – View the front element.
- Display – Show all queue elements.

4. Queue Using Linked List

This program implements a queue using a linked list with front and rear pointers.

Operations:

- Enqueue – Insert an element at the rear.
- Dequeue – Remove an element from the front.
- Peek – View the front element.
- Display – Show all queue elements.

Advantage: The queue can grow dynamically without requiring a fixed-size array.
